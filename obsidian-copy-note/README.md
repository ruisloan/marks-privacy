# Copy Note Text

Adds a **copy icon** to the note's action bar (top-right, next to the reading
view and the more-options `…` menu). Clicking it instantly copies the note's
**entire text** to your clipboard.

## Features

- Native copy icon in the action bar of every Markdown note.
- Copies the note's full Markdown content with a single click.
- Confirmation notice ("Note copied to clipboard ✓").
- A command is also available in the palette — **"Copy entire note text"** —
  so you can assign it a hotkey.
- Works on desktop and mobile.

## Installation

### From the Community plugins (recommended)

1. Open **Settings → Community plugins**.
2. Click **Browse**, search for **Copy Note Text**.
3. Click **Install**, then **Enable**.

### Manual installation

1. Create the plugin folder in your vault:
   `<your-vault>/.obsidian/plugins/copy-note-text/`
2. Copy `main.js` and `manifest.json` into that folder.
3. In Obsidian, go to **Settings → Community plugins** and enable
   **Copy Note Text**.

## Usage

Open any note and click the copy icon in the top-right action bar. The note's
entire text is immediately placed on your clipboard, ready to paste anywhere.

You can also run the command **"Copy entire note text"** from the command
palette and assign it a keyboard shortcut.
